# 照服員維護長者資料

1. 有效日照／居服人員可在授權長者頁查看基本與照護資料；所有請求即時檢查 tenant、角色、服務關係、單位、時間與 scope。未授權與不存在皆 404。
2. `elder:profile:update` 可修改姓名、稱呼、語言；`care_profile:write` 可新增、更正、停用照護資料。讀取分別需要 `elder:basic:read` 與 `care_profile:read`。不得修改登入帳號、同意或 AI Memory。
3. 每筆寫入必填原因，記錄操作者、時間、前後內容與版本。人工更正後是 RECORDED，不代表醫療驗證。DISPUTED 不得直接改成無爭議資料；RETIRED 不得恢復或更改。
4. 版本衝突回 409；同一冪等鍵與相同命令只寫一次，重播仍須有效授權。資料、歷史及最小 outbox event 同一交易提交。事件不得含姓名、照護內容、原因或快照。
5. 清單採 opaque cursor。介面提供中英、唯讀狀態、停用確認、衝突處理與授權失效清除，適用手機及平板。
6. 新建無帳號長者的建立人取得兩項獨立寫入權。既有資料僅補上有效機構收案、本人建立、同單位、無帳號長者、完全相符舊預設 scope 的有效日照關係；自訂與縮限權限不回填。
7. 不重啟已延後的真人語音驗收。
