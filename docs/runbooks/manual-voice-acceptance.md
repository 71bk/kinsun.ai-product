# 真人語音驗收操作清單

建立日期：2026-10-13。狀態：**尚未執行真人驗收**。這份清單不取代既有的合成音訊／SQL 測試，也不構成 production 核准。

## 前置條件

- 使用 development 與專用合成測試帳號、機構、長者資料；確認 actor、membership、scope 與收案仍有效。不能直接沿用已在 2026-09-29 到期的語音 campaign 權限。
- 測試者本人了解會使用外部 ASR／模型／TTS，並實際同意進行語音測試。照服員不得代替本人表達意願；尚未確認時不要勾選口頭同意。
- 確認 Core、Agent、Speech Gateway 與 frontend 都健康。這次公開問答 QA 的 3110／8110／8111 三服務不包含 Speech Gateway，不能直接視為語音測試環境。
- 沿用已核准的 development 語音設定與服務驗證，逐項確認 assisted session、voice ticket、ASR gate、TTS capability 及 Speech service identity；不要啟用 production 或改低信心門檻。
- 前端的 Speech Gateway URL、Core／Agent 內部位址及 frontend origin 必須與測試服務相符。瀏覽器須處於可使用麥克風的 secure context；手機／平板經區網測試時需有適當 HTTPS，不能把桌面 localhost 的例外當成真機可用證據。
- 金鑰、密碼、配對 token、session cookie、逐字稿與原始音檔不得放進版控或本驗收表。

## 操作

1. 照服員以自己的測試身份登入，開啟合成長者資料，選擇「準備陪伴平板」。
2. 說明用途、醫療限制及停止方式；取得測試者本人的明確意願後，記錄口頭確認。
3. 使用一次性連結配對全新瀏覽器 context／裝置，確認是長者模式，沒有照服員的登入狀態。
4. 選擇華語或 English，按「開啟語音陪伴」並處理原生麥克風權限。
5. 依下表逐項操作。使用固定合成句子，不描述真實姓名、病況、藥物或家庭資料。
6. 結束陪伴時段，確認所有收音 track 已停止，撤銷測試 session；保留合成稽核紀錄，不重建或清空共享資料庫。

| 項目 | 測試方式 | 應觀察行為 | 實際結果 |
| --- | --- | --- | --- |
| 麥克風拒絕 | 在新 context 拒絕權限 | 清楚說明無法收音，能恢復操作，沒有持續收音 | 未執行 |
| 華語兩輪 | 說「這是語音測試，我想聊聊音樂」，停頓後等回答，再說第二句 | 送出正確語言，能聽清楚回答，播放完成後續聽 | 未執行 |
| English 兩輪 | 另開時段，選 English，使用固定英語測試句 | ASR／回答／TTS 語言一致，不自動切換未支援語言 | 未執行 |
| 播放中暫停 | 回答播放時按暫停 | 音訊與收音停止，原生麥克風指示關閉 | 未執行 |
| 語音停止 | 聆聽時單獨說「停止」或 "stop" | 結束平板時段，回到配對流程，不送停止句給 Agent | 未執行 |
| 兩段無聲 | 開啟後保持安靜 | 自動暫停，沒有把無聲音訊當成有效對話 | 未執行 |
| 離頁與返回 | 收音時離開頁面，再返回 | 舊 track 釋放，不在背景持續收音或復活舊時段 | 未執行 |
| 換發失效 | 照服員重新準備同一合成長者的平板 | 舊平板、票券及 TTS capability 不再可用 | 未執行 |

播放期間的語音插話辨識目前不在這個切片內；以按鈕暫停驗收。低信心 gate 已有合成回歸，若真人測試未實際出現該情境，不得標為真人通過。

## 記錄與判定

每次記錄測試日期、裝置型號、作業系統、瀏覽器版本、網路類型、語言及每項結果。延遲填實際測量值，並記錄漏字、辨識錯誤、發音與操作問題；效能／音質的正式門檻仍需 Owner 定案，不能由這份清單自行核准。

任一權限／停止／失效檢查失敗，停止該輪並記錄可重現步驟。尚未執行、沒有對應觀察或只有合成結果的項目維持未驗收。
