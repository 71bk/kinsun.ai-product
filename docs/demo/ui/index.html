RWD

設計順序：先做 768 → 向上做 1024 → 最後才向下做 390。主要載具是平板，先做手機會讓平板變成「放大的手機」。

明確禁止

這些來自 AGENTS.md §4 與文件 04 §二，不是設計偏好。

  • 健康狀態燈號、風險分數、情緒指數、跨長者排名——顏色只表達 workflow 狀態，永遠不表達健康。
  • 趨勢預測與異常偵測視覺——文件 04 §十.7 禁止醫療趨勢預測，因此 Gate 1 不引入圖表函式庫。
  • 未確認記憶／未覆核事件／Draft Report 進入正式讀取路徑——虛線卡是「尚未成為事實」的形狀語言。
  • 家屬端渲染逐字稿、ASR 信心、內部筆記、未覆核事件——建議在 API client 加 runtime assert。
  • 恐懼、內疚、壓力或情緒依賴的設計——無連續天數懲罰、無倒數壓力、積分只加不扣。
  • emoji 當結構圖示、移除 focus ring、user-scalable=no、AI 紫粉漸層、深色模式（v0.1）
